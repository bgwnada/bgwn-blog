# bgwn.xyz

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
3. Run the app:
   `npm run dev`

Tip: Open http://localhost:5173 after running the dev server to view the site (Vite default).

To view the POSER assets you added, open the Music Catalog and click the POSER card; the three new images appear in that album's page.
